## Decisions (from 2026-05-20 review)

- **D1** — Propose the cleanest model honoring the draft's intent; existing Strapi types are mostly empty stubs and may be reshaped freely.
- **D2** — `News Item` is a full article collection type with a body and an `author` (a Member).
- **D3** — Partner and Sponsor are **one** content type (`Partner`) with an optional `sponsorshipLevel`. Drop the empty `partner-group` / `sponsor-group` collection types.
- **D4 / D8** — `Resource` covers both uploaded files (PDFs) and off-site long-form video; `Webinar` is a kind of `Resource`, not its own type. `Video Embed` stays a separate microsite component.
- **D5** — A "Member" is an **extended users-permissions `User`**, not a standalone type. Becoming a member provisions a login; permissions gate chapter-microsite management.
- **D6** — `Page` has an **optional** `chapter` relation: empty = global page, set = chapter microsite page.
- **D7** — Enums: Member `status` = Active / Lapsed / Pending / Honorary. Partner `sponsorshipLevel` = Platinum / Gold / Silver / Bronze.
- **D9** — `Contact Form` is a configurable component; anonymous submissions are stored as `Form Submission` records and delivered to the owning chapter's admins.
- **D10** — All attribute names are `camelCase`. Fix the misspelled `navigtaion` component.
- **D11** — Keep `Global`, `Top Nav`, `Footer`, `FAQ`. Delete `about` and `tk`.
- **D12** — The merged Partner/Sponsor type is named `Partner`.
- **D13** — Contact forms on global (non-chapter) pages route to a `Global.contactEmail` fallback.
- **D14** — Navigation supports one level of dropdown nesting (`nav-item` → `nav-link` children).
- **D15** — `/news`, `/events`, `/resources` index routes are dedicated front-end routes, **not** Strapi `Page` entries. Only detail views use slugs.
- **D16** — Dues are tracked by a single `duesPaidThrough` date; no payment-history type.

## Conventions

- **Content type API IDs**: singular `kebab-case` (`news-item`, `chapter`).
- **Component IDs**: `category.name`, e.g. `shared.section`. All page-level components live in the `shared` category.
- **Attributes**: `camelCase` (`primaryCta`, `linkUrl`, `feedUrl`).
- **Display names**: Title Case.
- **Draft & Publish**: enabled for editorial types (`page`, `news-item`, `event`, `resource`, `chapter`, `partner`); disabled for config single types and `form-submission`.
- **Relations** name the inverse side explicitly where it matters (e.g. `chapter.events` ↔ `event.chapter`).

## Content Types

### Member (extended `User`)

Implemented by extending `plugin::users-permissions.user` (in `src/extensions/users-permissions/content-types/user/schema.json`). The plugin already supplies `username`, `email`, `password`, `confirmed`, `blocked`, `role`.

| Attribute | Type | Notes |
|---|---|---|
| `firstName` | string | required |
| `lastName` | string | required |
| `displayName` | string | optional public-facing name |
| `image` | media (single, images) | profile photo |
| `bio` | text | optional |
| `status` | enum | `Active` / `Lapsed` / `Pending` / `Honorary` |
| `duesPaidThrough` | date | optional; drives lapsed status |
| `chapter` | relation manyToOne → `chapter` | the member's home chapter |
| `administeredChapters` | relation manyToMany → `chapter` | inverse of `chapter.administrators`; set for chapter admins |
| `title` | string | optional role/title shown in member listings |

Role-based permissions (Strapi roles) gate microsite management — a chapter admin is a `User` with the appropriate role plus an `administeredChapters` relation (see Chapter).

### Page

| Attribute | Type | Notes |
|---|---|---|
| `title` | string | required |

## Components

### Shared sub-components

**`shared.cta`** — a labelled link, reused across page components.

| Attribute | Type |
|---|---|
| `label` | string |
| `href` | string |
| `style` | enum: `Primary` / `Secondary` (optional) |

**`shared.nav-link`** — a leaf link: `label`, `url`.

**`shared.nav-item`** — a top-level nav entry: `label`, `url` (optional — leave empty when the item only opens a dropdown), `children` (repeatable `shared.nav-link`, optional) for dropdown submenus (D14).

**`shared.navigation`** — `items`: repeatable `shared.nav-item` (renamed from misspelled `navigtaion`; attribute was `NavItems`).

**`shared.social-link`** — `platform` (enum: Instagram / Facebook / LinkedIn / X / YouTube), `url`.

**`shared.form-field`** — one input in a contact form: `label`, `name` (machine key), `type` (enum: text / email / tel / textarea / select / checkbox), `required` (boolean), `placeholder`, `options` (text — newline-separated, for `select`).

### Page components (Page dynamic zone)

| Component | Attributes |
|---|---|
| `shared.section` | `title`, `body` (blocks), `figure` (media), `isHero` (boolean), `primaryCta` (`shared.cta`), `secondaryCta` (`shared.cta`) — replaces the four flat `primaryCTA*`/`secondaryCTA*` strings |
| `shared.news-and-resources` | `title`, `link` (`shared.cta`), `resources` (relation oneToMany → `resource`), `newsItems` (relation oneToMany → `news-item`) — the draft's "Latest News & Resources" |
| `shared.upcoming-events` | `title`, `link` (`shared.cta`), `events` (relation oneToMany → `event`) |
| `shared.member-group` | `title`, `link` (`shared.cta`), `members` (relation manyToMany → user) |
| `shared.partner-callout` | `title`, `body` (blocks), `link` (`shared.cta`), `partner` (relation oneToOne → `partner`) |
| `shared.partner-group` | `title`, `partners` (relation manyToMany → `partner`) — the draft's "Sponsors Group" |
| `shared.social-media-feed` | `title`, `platform` (enum), `feedUrl` |
| `shared.video-embed` | `title`, `videoUrl` (embed URL), `caption` — microsite promo clips (D8) |
| `shared.gallery` | `title`, `photos` (media, multiple, images) — the draft's "Photo Gallery" |
| `shared.contact-form` | `title`, `intro` (text), `fields` (repeatable `shared.form-field`), `submitLabel`, `notificationEmails` (string, optional override) — submissions stored as `Form Submission`, routed to the owning chapter's admins — or `Global.contactEmail` on global pages (D9/D13) |
